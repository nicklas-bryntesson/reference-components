How to test a tooltip

GIVEN THAT I am on a page with a tooltip

1 - Keyboard for mobile & desktop browser
- WHEN I use the arrow keys or tab key I SEE nothing, because we don't use tooltips

2 - Desktop screenreader
- WHEN I use a desktop screenreader (NVDA, JAWS, VoiceOver) AND 
- I use the arrow keys or tab key
  - I HEAR Nothing, because we don't use tooltips
3 - Mobile screenreader
- WHEN I use a mobile screenreader AND
  - I swipe
  - I HEAR Nothing, because we don't use tooltips

Full information: https://www.atomica11y.com/accessible-web/tooltip/
