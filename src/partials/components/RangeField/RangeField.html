RangeField

A styled native range: a track and a thumb, and nothing else. The browser positions the thumb, so there is no JavaScript here and nothing that could fall out of sync. The filled portion, tick marks, a value bubble and a reference band all belong to RangeScale, which composes this component.

Interaction states

A range always carries a value — there is no empty state, and required cannot express "no answer yet". So the two rows are at minimum and partially filled, not the family's usual empty/filled pair.
